## 0. 結論(先に置く)

**¥980/月のサブスクを「本命」に置くのをやめ、「継続」の段に戻す。** 本命は、決済実装を待たずに今日から売れる**買い切りの個人鑑定**に置く。

理由は3つ。

1. **サブスクは継続段であって本命段ではない**(offer-design §2)。P0で継続段を本命に据えると、供給が1週間止まった瞬間に解約の雪崩が起きる。星読みターフの供給は開催日に縛られており、夏の非開催週・冬の閑散期に必ず穴が開く。
2. **決済実装(Phase 5)が打席の前に立ちはだかっている。** 買い切りなら Stripe Payment Link 一枚で今日売れる。アプリに決済を組み込む必要がない。「リサーチ・OS整備・ツール選定が売らない言い訳になっていたら指摘する」(明鏡 柱7)——**決済実装待ちは、いま最大の言い訳になっている。**
3. **¥980×少数は個人の体力に見合わない。** 月10万円に106人必要。一方、本命¥19,800なら月5件。**5件の深い変化のほうが、106件の浅い接触より証言(証拠資産)が生まれる。**

## 2. 課金形態の裁定表(3案)

前提(すべて仮置き・要検証):
- 決済手数料 3.6%(Stripe)
- 現状のリスト数・フォロワー数は**未確認**。試算は逆算式のみを示す
- オーナーの制作時間は時給3,000円で機会費用に算入

### A案 — サブスク単独(現行 MONETIZATION.md 構想)

```
粗利/件 = 980 − 35 = 945円/月
LTV     = 945 ÷ 月次解約率
          解約率8%/月と置くと LTV ≈ 11,800円
月商10万円に必要な有料会員 = 100,000 ÷ 945 ≈ 106人
必要リスト = 106 ÷ 想定CVR
          CVR 1% → 10,600人  /  CVR 3% → 3,530人
```

- **前提条件:** アプリへの決済実装(Phase 5)完了。実オッズ連携(Phase 4)完了
- **リスク:** ①開催のない週に供給が止まり解約が出る ②到達までの期間が長い ③ゼロから1万人規模のリストが要る
- **撤退条件:** 有料転換が3か月で20人に届かない場合

### B案 — 本命逆算(推奨)

```
段構え:
  無料   : 毎日の物語+発信用ミニ(SNS)/ アプリ無料枠
  本命   : 個人鑑定「あなたと、今年の空」買い切り ¥19,800(仮)
  継続   : 星読みターフ プレミアム ¥980/月(本命購入者の受け皿。後から作る)

粗利/件 = 19,800 − 713 = 19,087円
月商10万円に必要な件数 = 100,000 ÷ 19,087 ≈ 5.2件/月(週1〜2件)
必要リスト = 5.2 ÷ 想定CVR
          CVR 1% → 520人  /  CVR 2% → 260人
制作時間  = 1件あたり2時間と置くと機会費用6,000円 → 実質粗利 13,087円/件
```

- **前提条件:** なし(Stripe Payment Link だけで今日から可能)
- **本命の中身(案):** 利用者の生年月日を入れた4者分析はエンジンが既に出せる。それを土台に、その人の一年の「空の重なり」を物語として書き下ろす。競馬を絡めるかは選べる形にする
- **リスク:** ①1件ごとに手間がかかり、件数が伸びると体力を食う(→上限を設けて希少性を正当化) ②鑑定文の品質がオーナーの筆に依存する
- **撤退条件:** 30件販売しても「変化の証言」が3件も出ない場合(=物語が刺さっていない)

### C案 — 支援パス型(応援課金)

```
粗利/件 = 500 − 18 = 482円/月
月商10万円に必要な支援者 = 208人
```

- **リスク:** 対価性が薄く、部族の熱量に完全依存。P0で熱量の実在が未検証な段階では賭けが大きい
- **使いどころ:** B案が回り始めたあとの、コミュニティ段の選択肢として保留

### 裁定

| | 打席に立つまで | 必要リスト規模 | 供給停止リスク | P0適性 |
|---|---|---|---|---|
| A案 サブスク | 決済実装待ち(長い) | 3,500〜10,600人 | **高**(開催に依存) | 低 |
| **B案 本命逆算** | **今日** | **260〜520人** | 低(受注制) | **高** |
| C案 支援パス | 数日 | 208人 | 中 | 中 |

**軍配: B案。** ただし決めるのはあなたです。

## 4. リーガル論点(出荷前に必ず潰す)

憲章 `MONETIZATION.md §4 やらないこと` との照合結果:

| 禁じ手 | B案は抵触するか |
|---|---|
| 1. 的中実績・回収率の広告 | **抵触しない**(ただし販売ページで検証記録を出す際、回収率を訴求に使わないこと) |
| 2. おすすめを馬券購入の推奨として表現 | **抵触しない**(物語の語り口は推奨表現を含まない) |
| 3. 外部予想の販売・転載 | 抵触しない(自社エンジンの鑑定) |
| 4. 無料ユーザーへの結論の出し惜しみ | **要注意** — 無料の物語は毎日フルで出し続けること |
| 5. データの規約違反取得 | 抵触しない |

追加で潰す論点:

- **特定商取引法**: 個人鑑定を販売するなら特商法表記(氏名または屋号・所在地・連絡先・返金条件)が必須。所在地の開示を避けたい場合の選択肢(バーチャルオフィス、プラットフォーム経由販売)は place.md で裁定する
- **景品表示法**: 「必ず○○になる」「的中率○%」の類は不可。**検証記録を実績として見せる場合、出典と日付と n を必ず併記**(いまの運用はこの点で既に強い)
- **占術サービスの表示**: 「結果を保証しない」旨は販売ページに書く。ただし**物語本文には書かない**(2026-08-02のオーナー指示。免責はページ側の定位置に1回)
- **JRDBデータの扱い**: 個人利用契約の範囲。鑑定成果物にJRDBの生データを転載しない
