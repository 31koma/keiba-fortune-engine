# 星読みターフをスマホから見る手順

方式は **Tailscale**。ネットには公開せず、自分のアカウントに入っている端末だけが
届く経路を作る。JRDBデータが外に出ないので個人利用契約の範囲から出ない。

## やること（3つだけ）

### 1. Mac に Tailscale
<https://tailscale.com/download/mac> → Googleアカウント(komatobi3@gmail.com)でログイン。
VPN構成の追加は「許可」。メニューバーが Connected になればOK。

### 2. iPhone にも Tailscale
App Store で「Tailscale」→ **Macと同じGoogleアカウント**でログイン。

### 3. 「スマホから見る設定.command」をダブルクリック
画面に出るアドレスを、iPhoneのSafariで開く。それだけ。

> 管理画面(admin console)での設定は**不要**。
> HTTPS証明書がONなら自動できれいなURLになり、OFFでも `http://100.x.x.x:3000`
> の形で繋がる。どちらもTailscaleが通信を暗号化しているので安全性は変わらない。

## 毎回のこと
- **Macを起動したままにする。** スリープすると繋がらない
  （システム設定 → ロック画面 → ディスプレイオフ後に自動でスリープ → しない）
- アプリが動いていること。止まっていたら「星読みターフを再起動.command」
- iPhone側のTailscaleが接続中であること

Safariで開いたら **共有 → ホーム画面に追加**。アプリのように使える。

## やめたいとき
```
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve reset
```

## いまのセキュリティ
| | |
|---|---|
| 画面(3000番) | このMacの中からだけ。カフェのWi-Fiで隣の人からは見えない |
| API(8000番) | 同上。画面の中継(/api)経由でしか触れない |
| 外への出口 | Tailscaleだけ。自分の端末以外は到達しない |
| ログイン | 8回間違えると15分ロック。パスワードはハッシュのみ保存 |

## まだやっていないこと
- パスワード変更（初期値がチャットに平文で流れている）→「パスワード設定.command」
- 本格的なデプロイ（Vercel + Supabase など。Macを起きっぱなしにしなくて済む形）
