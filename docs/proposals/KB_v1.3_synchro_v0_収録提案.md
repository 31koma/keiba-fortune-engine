「今日のシンクロ度」の算出規則を知識ベース正本へ新規ファイル `synchro_score.json` として収録することを提案する。

## 3. 規則の骨子(詳細はJSON本文)

- 構成要素: 馬×騎手の調和(zodiac.combined_score+group法の正規化平均)/馬×レース日の流れ(PD×UD一致)/あなた×馬の響き(PD一致)/集合意識の注目(オッズ→支持率近似→対数10点化)
- 重み: 0.30 / 0.25 / 0.20 / 0.25(利用者なしは再正規化: 0.375 / 0.3125 / 0.3125)
- 4象限パターン: 占術の流れ×集合意識 → 共鳴/隠れシンクロ/過熱/静観
- 5段階バンド: 9.0=gold 〜 0.0=red(フロント表示と鏡写し)
- おすすめ規則: 対象日の全出走を降順提示。タイブレークは hidden > resonance > その他

## 4. 正本側で確定・検討してほしい事項

1. 重み(特に集合意識0.25)の妥当性と出典整理(現状は出典なしの仮説)
2. 「オッズ=集合意識」という解釈の位置づけ(status_vocabのどの区分に置くか)
3. 支持率近似の控除率仮定(0.8)と、複勝・馬連等への拡張是非
4. 検証計画: verification_plan.json への追加(出生月統制に加え、**人気バイアスの統制**を必須記載——オッズを成分に含むため、的中率とオッズの相関はシンクロ度の検証にならない)
5. schema.sql のテーブル群との整合(readings系テーブルの正式定義。アプリは暫定で app_readings=アプリ運用テーブルに保存中)
6. 文言(パターン4種・バンド5種)の禁止語照合と表現の磨き込み
